Reconverse is a new scheduling and communication layer for Charm++. Charm++ previously relied on Converse for this functionality, but Converse is 30 years old and a replacement is appropriate to improve maintainability and add new features intended to improve performance. The focus of this talk is to describe the motivation for a new scheduling layer for task-based runtimes, the current progress of Reconverse development, new features and their impact on performance, and plans for the future of Reconverse.
